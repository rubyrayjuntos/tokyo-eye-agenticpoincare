4. Provenance gaps
========================================================================

- No runtime enforcement of the governance JSON provenance schema was found
  in the active science/data write path.
- Runtime authority is mostly Pydantic payload validation plus SQL schema,
  not the governance JSON schema itself.
- checkpoint_sha256 is required by governance but omitted in active compute,
  motif, and MD paths.
- code_version is schema-required but optional at runtime and commonly null.
- Manual provenance inserts in graph topology and duplicate-ingest audit use
  reduced field sets and bypass the richer schema contract.
- Validation evidence is not persisted as a strong structured provenance
  artifact in the inspected paths.

========================================================================
5. Hyperbolic vs euclidean separation assessment
========================================================================

Write path:
- Mostly separated.
- Adapter emits separate hyperbolic and euclidean runs/spaces.
- Normalizer stores them under distinct run_id/space_id combinations.

Read path:
- Not reliably separated.
- Motif analysis is structure-scoped rather than run-scoped.
- Legacy source-leak fallback also queries fact_gnn_node_embedding by
  structure only.

Assessment:
- Separation exists in storage, but not as a hard downstream trust boundary.
- The system is vulnerable to cross-run mixing and silent coercion of
  malformed hyperbolic rows.

- Trace every science-to-DB write path.
- Trace every downstream consumer query for run_id, space_id, and provenance
  completeness.
- Treat direct SQL paths as separate trust boundaries.

2. Live-data tests next
- For a structure like 4uj1, compare:
  checkpoint output -> adapter payload -> fact_gnn_node_embedding rows ->
  hydrate/consumer reads.
- Measure null provenance rates, run mixing, and hyperbolic radius
  distributions explicitly.

3. External benchmark validation after
- Corroborate stored hyperbolic geometry and downstream scientific calls
  against independent calculations, publications, lab findings, and MD
  validation before treating any derived view as authoritative.
